# Municipal Engineering Services Limited

**Engineering solutions for better communities.**

This repository contains the static website for Municipal Engineering Services Limited (MES), a Nigerian engineering, infrastructure, estate management, construction, and community development company.

## Website Sections

- **Home**: Company introduction, core strengths, services overview, and calls to action.
- **About**: MES vision, mission, values, and engineering philosophy.
- **Services**: Estate management, civil engineering, building construction, government approvals, and community development consultancy.
- **Specialization**: Drainage and community infrastructure services.
- **Projects**: Project categories and portfolio placeholders for roads, drainage, buildings, estate services, and community projects.
- **Insights**: Articles and topics covering infrastructure, drainage, estate management, approvals, housing, and road maintenance.
- **Contact**: Office details, phone numbers, email, WhatsApp contact, enquiry form, and map location.

## Local Usage

This is a static HTML website. No build process or package installation is required.

1. Open `index.html` directly in a browser, or
2. Serve the project folder with any local static web server.

The main assets are organized as follows:

```text
css/style.css   Site styles and responsive layout
js/main.js     Small navigation and contact-link helper
img/           Website images
lib/           Existing template and supporting assets
```

## Project Files

- `index.html` - Homepage
